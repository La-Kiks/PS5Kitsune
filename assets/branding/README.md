# Branding

The PS5Kitsune logo is a golden Inari kitsune mask. These SVG files are the sources; export PNG or ICO files from them when needed.

| File | Content |
| --- | --- |
| `kitsune-masque.svg` | Mask alone, transparent background (splash, welcome screen) |
| `kitsune-masque-48px.svg`, `-32px`, `-16px` | Simplified masks drawn for small sizes, not just scaled down |
| `kitsune-icone-encre.svg` | App icon on the ink background (default icon) |
| `kitsune-icone-vermillon.svg` | App icon on the vermillion background (alternative) |

The Windows icon used by the app is `src/PS5Kitsune.App/Assets/kitsune.ico` (ink variant, 16 to 256 px).
